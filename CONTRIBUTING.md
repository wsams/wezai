# Contributing

Thanks for trying wezai. The project is in **alpha** and still under heavy testing, so feedback from real use is especially valuable.

You do not need to write a long report. A short issue with a few basics is enough.

## Report a bug

[Open a bug issue](https://github.com/wsams/wezai/issues/new) and include:

1. **What you did** — the keybinding, palette action, or prompt (e.g. `CTRL+I`, `@git:status`, `#README.md fix typos`).
2. **What you expected** — one sentence is fine.
3. **What happened instead** — error text, wrong output, or “nothing happened”.
4. **Your environment** (when you know it):
   - OS (macOS, Linux, Windows)
   - WezTerm version
   - Shell (fish, zsh, bash, PowerShell, …)
   - Provider type (`http`, `ollama`, `local`, `google`) and model, if relevant

Screenshots or a short log snippet help, but are optional.

## Request a feature

[Open a feature issue](https://github.com/wsams/wezai/issues/new) and include:

1. **The problem or workflow** — what you are trying to do in the terminal.
2. **What you want** — the behavior or command you are asking for.
3. **Why it helps** — a line or two on how it would improve your workflow.

If you have a rough idea of how it might fit (palette action, `@` attachment, config option), mention that too.

## Before you file

- Search [existing issues](https://github.com/wsams/wezai/issues) to avoid duplicates.
- Redact API keys, tokens, and other secrets from prompts, configs, and logs.

## Code contributions

Pull requests are welcome. For larger changes, open an issue first so we can agree on direction before you spend time on a big diff.
